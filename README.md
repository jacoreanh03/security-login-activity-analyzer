# Security Login Activity Analyzer

A Python portfolio project that analyzes **synthetic** authentication logs, counts successful and failed login attempts by IP address, flags IPs that meet a configurable failed-login threshold, safely skips malformed records, and exports a CSV review report.

## Features
- Parses timestamp, IPv4 address, and SUCCESS/FAIL status from each log line.
- Counts successful and failed attempts per IP address.
- Flags addresses with failed attempts greater than or equal to the threshold.
- Skips malformed records and reports how many were skipped.
- Exports flagged addresses to CSV.
- Includes five unit tests.

## Requirements
- Python 3.10 or newer
- No third-party packages required

## Run
From this project directory:
```bash
python src/main.py
```

Change the failed-login threshold or file paths:
```bash
python src/main.py --input data/sample_auth.log --output reports/flagged_ips.csv --threshold 5
```

## Run tests
```bash
python -m unittest discover -s tests -v
```

## How it works
1. Read each line in the synthetic log file.
2. Validate the line format and IPv4 octets.
3. Count SUCCESS and FAIL events by IP address.
4. Compare failed counts with the configured threshold.
5. Export flagged IPs and failed-attempt counts to CSV.

## Example output
The included sample data should produce two flagged addresses at the default threshold of five, plus one malformed record skipped. Exact output is generated by running the program.

## Limitations and responsible use
This project uses fabricated sample records for learning and demonstration. It is not connected to a real identity provider, does not block traffic, and does not prove that an IP address is malicious. A flagged address is simply a record that met the configured threshold and should be reviewed in context.
